# Cracktros

A desktop application for image conversion and compression, built with [Rust](https://www.rust-lang.org/) and [egui](https://github.com/emilk/egui).

Cracktros is a personal project built around a collection of image utilities I use regularly, with an interface and theme designed to my own preferences.

The aim is to create a simple, lightweight tool that brings image conversion and compression together in one place, with a custom look and feel.

Currently in development.
